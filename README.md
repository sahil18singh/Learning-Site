*Learning Site* is a full-stack e-learning platform where instructors can upload and sell their own courses, and students can purchase, rate, and learn from them. It supports video content, file uploads, secure OTP-based authentication, role-based access control, and course reviews — making it suitable for all domains like technology, arts, and more.

🚀 *Live Demo:* [https://learning-site-wheat.vercel.app/](https://learning-site-wheat.vercel.app/)

---

## ✨ Key Features

### 🔐 Authentication & Security
- Secure user *registration & login*
- *OTP-based email verification*
- *JWT-based* session handling
- *Role-based access*: Student / Instructor

### 📁 Course Management
- Instructors can:
  - Upload courses with videos and descriptions
  - Set course pricing and categories
- Students can:
  - View all courses
  - Purchase & access paid courses

### 🌟 Course Rating & Reviews
- Students can *rate courses (1–5 stars)*
- Each course displays *average rating* and *number of reviews*
- Optionally, add *text feedback/comments*

### 🧑‍🎓 Student Features
- View course
- Purchase and access content
- Rate and review courses after completion

### 👨‍🏫 Instructor Features
- Dashboard to manage uploaded courses
- Track number of enrollments
- View student feedback

## ⚙ Tech Stack

### Frontend
- React.js
- Axios
- React Router DOM
- Redux or Context API

### Backend
- Node.js
- Express.js
- MongoDB (via Mongoose)
- Express-Fileupload (file uploads)
- JWT for authentication
- Nodemailer (for OTP)
